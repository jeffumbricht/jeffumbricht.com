# jeffumbricht.com

[![Netlify Status](https://api.netlify.com/api/v1/badges/9420a537-a027-4203-a00a-9b0f8e17b66c/deploy-status)](https://app.netlify.com/sites/stoic-mestorf-86d39b/deploys)

Personal site for Jeff Umbricht, built with [Astro](https://astro.build), React, TypeScript and Tailwind CSS.

Design based on [Spectral](https://html5up.net/spectral) by HTML5 UP, used under the [CCA 3.0](https://html5up.net/license) license.

## Quick Start

Requires Node 22 (see `.nvmrc`).

```sh
npm install
npm run dev      # local dev server
npm run build    # type check (astro check) + static build into dist/
npm run preview  # serve the built site
npm run format   # Prettier
```
